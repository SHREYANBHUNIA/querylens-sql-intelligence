# QueryLens Interface Direction

The redesigned interface uses an **operational query-console template** rather than a centered, marketing-style landing page. Its primary surface is a dark SQL workbench placed within a light application shell, supported by an inspection-status rail, contextual diagnostics, and a persistent performance-history panel.

The visual verification confirmed that the page is readable at desktop width, the SQL editor is the dominant task surface, and the workflow hierarchy is clear: input, inspect, compare, then review history. Electric indigo is reserved for active inspection and primary actions, while green indicates engine health.
